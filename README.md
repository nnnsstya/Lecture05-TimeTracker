# Практическое задание к лекции № 5

## Модуль учёта времени для системы управления задачами + премирование сотрудников

### Цель

Разработать модуль для запуска и остановки таймера задач, подсчёта затраченного времени, генерации отчётов и интеграции с системой управления задачами из примера лекции № 5.

### Соответствие требованиям

1. **Старт/остановка таймера** — методы `TimeTracker.start_timer(task_id)` и `TimeTracker.stop_timer(task_id)`. Повторный запуск одного активного таймера запрещён.
2. **Учёт общего времени** — `TimeTracker.get_total_seconds(task_id)`. При нескольких запусках время суммируется; активный таймер также учитывается.
3. **Генерация отчётов** — `TimeTracker.generate_report()` и `TimeTracker.export_csv(...)`. CSV открывается в Excel.
4. **Интеграция** — модуль `time_tracker.py` использует `TaskManager` и ID задач, уже заведённых через `TaskManager.create_task`, и показывает исполнителя/статус из системы задач.

### Структура проекта

- `task_manager.py` — пользователи, задачи, статусы и приоритеты (по структуре примера лекции).
- `time_tracker.py` — интервалы работы, таймеры, подсчёт времени и отчёты.
- `storage.py` — автоматическое сохранение и загрузка JSON.
- `main.py` — консольное меню для пользователя.
- `test_time_tracker.py` — 17 автоматических тестов основной системы.
- `reward_system.py` — дополнительная система премирования.
- `test_reward_system.py` — 17 автоматических тестов премирования.
- `reward_report.csv` — формируется при выборе пункта 10 (рейтинг сотрудников).
- `tasks_data.json` — появляется автоматически после первого сохранения (не требуется создавать вручную).
- `time_report.csv` — появляется после выбора пункта «Экспортировать отчёт».

### Запуск в PyCharm

1. Создайте проект **Pure Python** (Python 3.9 или новее).
2. Откройте папку с этими файлами через **File → Open** либо скопируйте все `.py` и `README.md` в корень проекта.
3. Откройте файл `main.py` и нажмите зелёный треугольник **Run 'main'**. Никаких внешних библиотек ставить не нужно.
4. Создайте задачу (пункт `1`), посмотрите задачи (пункт `2`), запустите её таймер (`3`), затем остановите (`4`), сформируйте отчёт (`5`) и сохраните CSV (`6`).
5. Чтобы показать интеграцию с системой задач, выберите пункт `7` и назначьте исполнителя; имя исполнителя появится в отчёте.

**Важно:** после закрытия и повторного запуска программы задачи и интервалы не пропадают. Если таймер был запущен и не остановлен, он продолжит учитывать время до следующей остановки. Для реального контроля времени не оставляйте его активным без необходимости.

### Этапы разработки (по лекции № 5)

1. **Анализ требований:** выделены четыре функции, перечисленные в задании.
2. **Проектирование:** использованы классы `TaskManager`, `Task`, `User`, `TimeTracker`, `TimeEntry`; связь таймера с задачами построена по `task_id`.
3. **Реализация:** написаны модули Python с разделением ответственности; сохранение — JSON, отчёт — CSV.
4. **Тестирование:** автоматические проверки старта/остановки, расчёта времени, отчёта, экспорта, ошибок и сохранения.
5. **Внедрение:** локальный запуск через PyCharm, зависимости только из стандартной библиотеки Python.
6. **Сопровождение:** модули разделены, код снабжён строками документации и пригоден для расширения.

### Ограничения

- Это учебное консольное приложение, а не готовая серверная система.
- Файлы JSON предназначены для одного экземпляра приложения, не для параллельной записи с нескольких компьютеров.
- Время отображается в полных секундах, а точность внутренних расчётов — до долей секунды.
- Запущенный таймер продолжает считать время после закрытия программы, так как момент начала сохраняется в JSON.


## Дополнительная функция для бонусного балла: премирование сотрудников

**Цель:** мотивировать сотрудников завершать задачи в срок, а также
показывать результаты в виде рейтинга. Все баллы условные и не являются деньгами.

Правила начисления (приняты для учебного примера):

| Когда задача завершена | Баллы |
| --- | ---: |
| Не менее чем за 24 часа до дедлайна | 15 |
| В срок, но менее чем за 24 часа до дедлайна | 10 |
| После дедлайна | 0 |

**Порядок демонстрации в PyCharm:**

### Проверка системы премирования

1. Запустите программу `main.py`.
2. Нажмите **1**, чтобы создать новую задачу и установить срок её выполнения.
3. Нажмите **7**, чтобы назначить исполнителя созданной задачи.
4. Нажмите **2**, чтобы проверить наличие задачи в системе.
5. Нажмите **8**, укажите ID созданной задачи. Программа завершит задачу и автоматически начислит премиальные баллы в зависимости от срока выполнения.
6. Нажмите **9**, чтобы просмотреть рейтинг сотрудников с количеством начисленных баллов.
7. Нажмите **10**, чтобы сохранить рейтинг в файл `reward_report.csv`.
8. Повторное начисление баллов за одну задачу запрещено. Для проверки премирования других сотрудников необходимо создать дополнительные задачи и назначить исполнителей.

Дополнительные проверки:
- Без назначенного исполнителя завершить задачу нельзя.
- Если таймер работает, нужно сначала остановить его.
- После завершения задачи запрещено повторно запускать её таймер
  и менять исполнителя (защита от неверного начисления).
- Результаты премирования сохраняются в `tasks_data.json` и
  восстанавливаются после закрытия PyCharm. Старый формат JSON без
  полей бонусов тоже поддерживается.

**На защите:** «В дополнение к обязательным требованиям я реализовала
систему премирования сотрудников. При завершении задачи программа
сравнивает фактическую дату с дедлайном, начисляет 0, 10 или 15 баллов
и строит рейтинг сотрудников. Это позволяет поощрять соблюдение сроков».
